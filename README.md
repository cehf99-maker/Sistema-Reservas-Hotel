# Sistema-Reservas-Hotel

Proyecto académico desarrollado bajo la metodología **Scrum**  
por el **Grupo 1 - Honores** para la asignatura *Metodología de Desarrollo de Software*.

---

## 🚀 Descripción
El sistema busca digitalizar y optimizar el proceso de reservas y hospedajes en hoteles pequeños, evitando sobreventas y mejorando la experiencia del cliente a través de una plataforma web fácil de usar.

---

## 🧩 Tecnologías utilizadas
- **Backend:** Java / MySQL  
- **Frontend:** HTML, CSS, JavaScript  
- **Gestión ágil:** Trello y Jira  
- **Control de versiones:** GitHub  

---

## 🗓️ Sprints

| Sprint | Entregables principales |
|--------|--------------------------|
| **Sprint 1** | Registro e inicio de sesión, gestión de habitaciones |
| **Sprint 2** | Reservas, historial, pagos en línea |
| **Sprint 3** | Servicios extra, reportes y roles de usuario |
